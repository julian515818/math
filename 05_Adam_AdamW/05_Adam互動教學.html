0一句話直覺：Adam ＝ 動量 ＋ RMSProp ＋ 偏差修正

θt = θt−1 − η · m̂t√v̂t + ε 　　（一階矩給方向，二階矩調尺度）
① 一階矩 m（動量）mt = β1mt−1 + (1−β1)gt
梯度的指數移動平均：平均往哪走，雜訊互相抵消。來自 Polyak 的動量。
② 二階矩 v（RMSProp）vt = β2vt−1 + (1−β2)gt²
梯度平方的指數移動平均：梯度通常多大。來自辛頓的 RMSProp。
③ 偏差修正m̂t = mt1−β1t，v̂t = vt1−β2t
m0 = v0 = 0，初期估計偏向 0，要放大回來。

符號：步數 t = 1, 2, …；梯度 gt = ∇f(θt−1)；平方、開根號、除法都是逐元素計算。論文建議的預設值：η = 0.001、β1 = 0.9、β2 = 0.999、ε = 10−8（論文把學習率寫成 α，本系列統一用 η）。

📜 小故事：兩位實習生的優化器

2014 年夏天，辛頓的博士生吉米・巴和剛提出變分自編碼器（VAE）的迪德里克・金馬（Diederik Kingma）在倫敦的 DeepMind 實習。VAE 的訓練要隨機取樣，梯度充滿雜訊，金馬需要一個更穩、更不必反覆調參的優化器。

他們把動量的一階矩和 RMSProp 的二階矩結合起來，再加上關鍵的偏差修正。名字 Adam 不是縮寫，而是來自 adaptive moment estimation（自適應矩估計）。

1一步一步算 Adam：每一行程式在做什麼？

最小化 f(θ) = (θ − 3)²，從 θ0 = 0 出發，η = 0.1、β1 = 0.9、β2 = 0.999、ε = 10−8。每按一次「下一步」執行一行：

f(θ) = (θ − 3)²Adam 走過的位置

觀察 Δθ 欄：梯度從 −6 一路變小，Adam 的步長卻一直維持約 η = 0.1。因為 m̂ ≈ g、√v̂ ≈ |g|，兩者相除只剩方向。同樣的 η，SGD 第一步會走 η·|g| = 0.6。

2偏差修正：為什麼要除以 1 − βt？

假設梯度一直是 g = 1。因為 m0 = v0 = 0，展開等比級數可得 mt = (1 − β1t)·g、vt = (1 − β2t)·g²：剛開始都偏向 0，除以 1 − βt 剛好把它還原。

📌 沒有修正時，分子 m 約 10 步就追上，分母 √v 卻要上千步才追上（β2 = 0.999 記得約 1000 步）。結果前幾百步的步長是 η 的好幾倍，訓練一開始就可能衝過頭。這正是 RMSProp 加動量時沒處理的問題，也是 Adam 的關鍵改良。

3步長的性質：m̂√v̂ 像「訊號雜訊比」，雜訊大就自動煞車

讓梯度 = 平均 μ ＋ 雜訊（標準差 σ），跑 300 步 Adam（β1 = 0.9、β2 = 0.999）。因為 m̂ ≈ μ、v̂ ≈ E[g²] = μ² + σ²：

這也說明 η 的意義：在 Adam 裡，η 大約就是每一步參數最多移動多少。不管梯度是 0.001 還是 1000，步長都在 η 左右，所以同一組預設值能用在很多不同的問題上。

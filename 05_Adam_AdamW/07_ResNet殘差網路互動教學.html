ResNet 殘差網路互動教學

工程數學 ・ 互動教學：深度學習（Deep Learning）中的殘差學習（Residual Learning）——為什麼加一條「捷徑」就能訓練上百層的網路？

靜宜大學晶片設計學士學位學程劉志俊 老師

0一句話：不要學「答案」，學「要改多少」

一般的層要直接學出目標映射 H(x)；
殘差區塊只學「差多少」：F(x) = H(x) − x，再把輸入加回去
y = F(x) + x

ResNet（Residual Network，殘差網路）由何凱明、張祥雨、任少卿、孫劍於 2015 年提出（論文〈Deep Residual Learning for Image Recognition〉）。那條把 x 直接送到後面相加的線，叫做捷徑連接（shortcut / skip connection）；它不增加任何參數，卻讓 152 層的網路也訓練得動。

大家好！我是何凱明。這一頁帶你看懂 ResNet 的「捷徑」。點我聽故事！

1越深越好？「退化問題」（Degradation）

直覺上，網路越深、能力越強。但實驗發現：把一般的卷積網路（論文稱為 plain 網路）從 18 層加深到 34 層，錯誤率反而上升——而且連訓練誤差都變高，所以不是過擬合（overfitting），而是「深的網路比較難訓練」。

奇怪的地方：34 層的網路其實可以「至少跟 18 層一樣好」——只要把前 18 層照抄，多出來的 16 層全部學成恆等映射（identity），輸出就和 18 層一模一樣。可見問題出在：一疊非線性層很難學會「什麼都不做」。

資料：論文 Table 2，ImageNet 驗證集 top-1 錯誤率（%，10-crop 測試）。越低越好。

2殘差區塊：y = F(x) + x

左邊兩個「權重層」（論文中是 3×3 卷積＋BatchNorm）合起來就是 F(x)；右邊的弧線是捷徑，把 x 原封不動送到 ⊕ 相加，最後再過 ReLU。關掉捷徑，就變回 plain 網路的兩層。

3為什麼「學殘差」比較容易？

假設這一層最理想的輸出 H(x) 很接近輸入本身（深層網路裡常常如此：每一層只需要做一點點修正）。

訓練剛開始時權重都很小，各層的輸出接近 0：

  • Plain：輸出 ≈ 0，離目標很遠，要從頭學出整個 H(x)。
  • 殘差：輸出 ≈ 0 + x = x，一開始就接近目標，只要再學一點點修正 F(x)。

4梯度的高速公路

反向傳播時，梯度要從最後一層一路乘回第一層（連鎖法則）：

Plain： ∂L∂x0 = ∂L∂xL · ∂fL∂x ⋯ ∂f1∂x 　← 很多小於 1 的數相乘 → 趨近 0（梯度消失）
殘差： ∂L∂x0 = ∂L∂xL · (1 + ∂FL∂x) ⋯ (1 + ∂F1∂x)

把兩個區塊乘開：(1 + F′2)(1 + F′1) = 1 + F′1 + F′2 + F′2F′1。
不管疊多少層，展開後永遠有一項是 1——梯度可以沿著捷徑直接走回最前面。

Plain：第 1 層梯度大小
殘差：第 1 層梯度大小
Plain：h ← tanh(Wh)殘差：h ← h + 0.5·tanh(Wh)

這是在你的瀏覽器裡真的算出來的：寬度 16 的 tanh 網路，隨機權重，最後一層梯度大小設為 1，往回做反向傳播，畫出每一層的 ‖∂L/∂h‖（對數刻度）。真正的 ResNet 還有 BatchNorm 控制分支大小，這裡用 0.5 倍代替。試著改 σ：plain 只有在 σ 剛好合適時梯度才不會消失或爆炸，殘差則在很大範圍內都穩定。

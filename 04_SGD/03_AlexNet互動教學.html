AlexNet 是 2012 年由 Alex Krizhevsky、Ilya Sutskever 與 Geoffrey Hinton 提出的卷積神經網路（Convolutional Neural Network, CNN）。它在 ImageNet 影像辨識競賽中，把 top-5 錯誤率從第二名的 26.2% 一口氣降到 15.3%，從此開啟深度學習時代。

整個網路可以用一句話記住：5 層卷積「看圖找特徵」＋ 3 層全連接「根據特徵做判斷」。

3卷積 → ReLU → 最大池化：實際算給你看

AlexNet 第一層的濾波器學到的多半是「邊緣、顏色變化」偵測器。下面用 3×3 濾波器在一張 96×96 的灰階貓圖上真的做一次卷積。點中間的卷積結果任一點，看那一點是怎麼算出來的。

濾波器：

卷積結果：橘色＝正值、藍色＝負值。ReLU 把負值全部變成 0；池化用 3×3、步長 2（和 AlexNet 一樣是重疊池化）。

濾波器權重：
點卷積結果上的任一點……
尺寸：96 → ⌊(96 − 3 + 0)/1⌋ + 1 = 94（卷積）→ 94（ReLU 不改尺寸）→ ⌊(94 − 3)/2⌋ + 1 = 46（池化）。AlexNet 的 Conv1 有 96 個這樣的濾波器，而且每個是 11×11×3，同時看紅綠藍三個通道。

4AlexNet 的兩個關鍵武器：ReLU 與 Dropout

ReLU：梯度不會「飽和」

x = 2.0
sigmoidtanhReLU實線＝函數　虛線＝導數（梯度）

sigmoid、tanh 在 |x| 很大時導數趨近 0（飽和），反向傳播時梯度一層層變小。ReLU = max(0, x) 在 x > 0 時導數固定為 1。AlexNet 論文指出，用 ReLU 的 CNN 訓練速度比 tanh 快好幾倍。

Dropout：訓練時隨機關掉一半神經元

AlexNet 的 FC6、FC7 後面都接 Dropout(0.5)。全連接層參數多、最容易過擬合（overfitting）；隨機關掉神經元，逼網路不能只依賴少數特徵。只有約 3,700 張訓練圖的貓狗資料集更需要它。

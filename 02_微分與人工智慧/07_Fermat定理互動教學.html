Fermat 定理：極值點的切線是水平的

工程數學 ・ 互動教學：為什麼找最大值、最小值時要解 f′(x) = 0？

靜宜大學晶片設計學士學位學程劉志俊 老師

0定理敘述

若 f(a) 是區域極大值或區域極小值（local maximum / minimum），
而且 f′(a) 存在，則　f′(a) = 0
區域極大值在 a 附近，f(a) 最大：f(a) ≥ f(x)（像小山頂）
區域極小值在 a 附近，f(a) 最小：f(a) ≤ f(x)（像小山谷）
兩個前提① a 在定義域的內部（左右兩邊都能走）② f′(a) 存在（沒有尖角）

一句話：在光滑曲線的山頂或山谷，切線一定是水平的。所以要找極值，就先找出所有讓 f′(x) = 0 的點。

1直覺：走到山頂時，腳下是平的

登山比喻：沿著曲線由左往右走。上坡時切線斜率為正，下坡時為負。從上坡變成下坡的那一瞬間（山頂），斜率必須經過 0，切線是水平的。山谷也一樣，只是由下坡變上坡。

拖動 a，觀察橘色切線：在山頂和山谷時變成水平，斜率顯示為 0。

2為什麼一定是 0？看左右兩邊的割線斜率

導數的定義：f′(a) = limh→0 f(a+h) − f(a)h。以區域極大值為例，在 a 附近 f(a) 最大，所以分子 f(a+h) − f(a) 一定 ≤ 0。接下來只看分母 h 的正負號：

4應用：找閉區間上的最大值與最小值

Fermat 定理告訴我們：極值只可能出現在三種地方，稱為候選點：① f′(x) = 0 的點　② f′(x) 不存在的點　③ 區間的端點。把候選點全部代入 f 比大小，就找到了最大值和最小值，不用檢查無限多個點。

和機器學習的關係：訓練神經網路就是找損失函數 L 的最小值。Fermat 定理的多變數版本說：在最小值處，所有偏導數都是 0，也就是梯度 ∇L = 0。梯度下降一直往下坡走，直到梯度（坡度）接近 0 才停下來，就是在找這個「水平的谷底」。

5人物小檔案：Pierre de Fermat

Bonjour！我是費馬。點我一下。

皮埃爾·德·費馬（Pierre de Fermat，1601（一說 1607）–1665），法國人。他的正職是土魯斯（Toulouse）地方法院的律師與法官，數學只是業餘興趣，卻被後人稱為「業餘數學家之王」。

  • 比牛頓、萊布尼茲更早的「微積分」：1630 年代，他用「近似相等（adequality）」的方法，讓 f(a+h) 和 f(a) 近似相等，再令 h 趨近 0，來求極大值、極小值與切線。這正是本頁定理的原型。
  • 費馬原理（光學）：光在兩點間行進，會走「花費時間最少」的路徑，由此可以推出折射定律。這也是一個求極值的問題。
  • 費馬最後定理：他在書頁空白處寫下「xⁿ + yⁿ = zⁿ 在 n > 2 時沒有正整數解，我發現了絕妙的證明，但這裡空白太小寫不下」。這個問題困擾數學家三百多年，直到 1994 年才由 Andrew Wiles 證明（1995 年發表）。
  • 他也和帕斯卡（Pascal）透過書信共同奠定了機率論的基礎。

0從費馬定理到機器學習

模型有一組參數 θ = (θ₁, θ₂, …)（例如神經網路的權重 W、b）。每一組參數都對應一個損失 L(θ)，代表模型錯得多嚴重。訓練就是找讓 L 最小的參數 θ*。

費馬定理（多變數版）：若 L 在 θ* 有區域極小值且可微，則
∇L(θ*) = 0，也就是 ∂L∂θ₁ = ∂L∂θ₂ = ⋯ = 0

為什麼？沿著 θ₁ 方向切一刀，得到一條一維曲線，θ* 在這條曲線上也是最低點，由一維費馬定理得 ∂L/∂θ₁ = 0；每個方向都一樣，所以整個梯度是 0：谷底是平的。

方法 A：直接解 ∇L = 0

簡單的損失函數（例如線性迴歸的 MSE）可以直接解方程式得到 θ*，一步到位。

方法 B：梯度下降

神經網路的 L 太複雜，無法直接解。那就從任意位置出發，沿著負梯度往下走，一直走到 ∇L ≈ 0（費馬定理告訴我們：谷底就是這樣的地方）。

1先看一維：只有一個參數 θ

損失函數 L(θ) = ½(θ − 3)² + 0.5　　L′(θ) = θ − 3

梯度下降：θ ← θ − η·L′(θ)。在谷底左邊 L′ < 0，所以 θ 往右走；在右邊 L′ > 0，θ 往左走；到谷底 L′ = 0，就停下來了。試試把 η 調到 2 以上會怎樣。

3重點整理

費馬定理說的在訓練中的意義
極小值處 ∇L = 0訓練收斂時，梯度接近 0，參數幾乎不再改變：可以用 |∇L| 很小當作停止條件。
反過來不一定成立∇L = 0 的點也可能是鞍點或區域極小值，不一定是全域最小值（見第 2 節「雙谷」、「鞍點」）。
要可微才適用所以神經網路要選擇可微（或幾乎處處可微）的激活函數與損失函數，才能用梯度找谷底。
定理只告訴我們「谷底長什麼樣子」怎麼走到谷底，要靠梯度下降，並選擇適當的學習率 η：太小走得慢，太大會震盪甚至發散。

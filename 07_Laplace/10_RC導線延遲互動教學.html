3Laplace 觀點：把 π 模型解出來，畫出步階響應

① 原來的微分方程式（時域）

電容電流 i = C dvdt。對兩個節點寫 KCL（流進電容的電流 ＝ 流進節點的淨電流）：

節點 1：C1 dv1dt = vin − v1Rd − v1 − v2Rw
節點 2：C2 dv2dt = v1 − v2Rw

C1 = Cw/2，C2 = Cw/2 + Cin；初始條件 v1(0) = v2(0) = 0（電容一開始沒有電）。兩條互相耦合的微分方程式，直接在時域解很麻煩。

② Laplace 轉換：微分變成乘以 s

ℒ{ dvdt } = sV(s) − v(0) = sV(s)

兩邊同取 Laplace 轉換（小寫 v(t) → 大寫 V(s)），初始值為 0：

節點 1：sC1V1 = Vin − V1Rd − V1 − V2Rw
節點 2：sC2V2 = V1 − V2Rw

沒有任何微分了，只剩代數方程式！這等同於直接把電容換成阻抗 1/(sC)。

③ 解代數方程式（移項、代入）

由節點 2：V1 − V2 = sRwC2V2　⇒　V1 = (1 + sRwC2) V2
節點 1 兩邊乘 Rd：Vin = (1 + sRdC1) V1 + RdRw(V1 − V2)
用節點 2 的結果 RdRw(V1 − V2) = sRdC2V2：
Vin = (1 + sRdC1) V1 + sRdC2V2
代入 V1：Vin = [ (1 + sRdC1)(1 + sRwC2) + sRdC2 ] V2
展開：Vin = [ 1 + s(RdC1 + RdC2 + RwC2) + s2RdC1·RwC2 ] V2

0一句話直覺：轉半圈到 −1，再加 1 回到原點

由歐拉公式 eiθ = cos θ + i sin θ，代入 θ = π：eiπ = cos π + i sin π = −1 + 0i = −1，移項就得到 eiπ + 1 = 0。

2從「複利」走到 −1：(1 + iπ/n)n → eiπ

e 誕生於複利：e = lim (1 + 1n)n。把「利率」換成虛數 iπn：每乘一次 (1 + iπn)，就是轉一個小角度、再放大一點點。乘 n 次之後，n 越大，終點越接近 −1。

折線：1 → (1+iπ/n) → (1+iπ/n)2 → ⋯ → (1+iπ/n)n　× ＝ −1

對照實數版：(1 + 1/n)n 是複利，會趨近 e ≈ 2.71828；虛數版的「複利」不是讓錢變多，而是讓點沿著單位圓轉到 π。

4為什麼被稱為「最美的公式」？

古希臘畢達哥拉斯學派相信「萬物皆數」，把數與比例看成宇宙的本質。歐拉恆等式讓許多人產生類似的敬畏：五個毫不相干的常數，竟以最基本的運算結合在一起。下面是有紀錄可查的評價：

費曼：「我們的寶石」理查・費曼 14 歲時在筆記本上稱它為數學中最了不起的公式；後來在《費曼物理學講義》中稱歐拉公式為「我們的寶石」（our jewel）。
讀者票選第一名1990 年《數學情報》（The Mathematical Intelligencer）公布 David Wells 的「最美定理」讀者調查，歐拉恆等式名列第一。
與馬克士威方程組並列2004 年《物理世界》（Physics World）讀者票選「最偉大的方程式」，歐拉恆等式與馬克士威方程組並列榜首。
大腦真的覺得它美2014 年 Zeki 等人的腦造影研究：數學家看到被評為美的公式時（歐拉恆等式最常被評為最美），大腦內側眼窩額葉皮質被激活──和欣賞音樂、藝術時是同一區。
莎士比亞十四行詩數學家 Keith Devlin 說，它就像一首捕捉了愛之本質的莎士比亞十四行詩，觸及數學存在的最深處。
「我們不懂，但它必定為真」19 世紀哈佛數學家 Benjamin Peirce 在課堂證明後，據學生回憶說：這完全違反直覺，我們不理解它的意義，但已經證明了，所以它一定是真的。

現代文化裡，有人把 eiπ + 1 = 0 刺在手臂上或做成項鍊，當作對理性之美的「信仰宣示」。

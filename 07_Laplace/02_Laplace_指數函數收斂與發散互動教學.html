0一句話直覺：a 的正負決定一切

f(t) = eat，  t ≥ 0

指數函數的命運只看指數裡的 a：a < 0 收斂到 0、a = 0 不動、a > 0 發散到 ∞。Laplace 轉換的核心就是拿另一個指數 e−st 去和它比賽。

a < 0：收斂（Convergent） e−t → 0
a = 0：常數 e0 = 1
a > 0：發散（Divergent） et → ∞

1動手調 a：看 eat 往上衝還是往下掉

灰色虛線：a = −1、0、1 的參考曲線

觀察：a > 0 時每隔固定時間 ln 2a 就「加倍」；a < 0 時每隔 ln 2|a| 就「減半」。指數函數的增長或衰減是等比例的。

2拔河比賽：e−σt 能不能壓住 eat？

Laplace 轉換 F(s) = ∫0∞ e−stf(t) dt。先只看實數 s = σ：被積函數是 eat · e−σt = e(a−σ)t，紫色面積就是積分值。

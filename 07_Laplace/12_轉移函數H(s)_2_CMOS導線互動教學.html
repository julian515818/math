轉移函數 H(s)（二）CMOS 長導線

工程數學 ・ 互動教學：反向器驅動長導線，H(s) 變成 N 階，為什麼還能用一階近似？

靜宜大學晶片設計學士學位學程劉志俊 老師

0一句話：導線的 H(s) 有 N 個極點，但主極點讓它「看起來」像一階

H(s) = 11 + a₁s + a₂s² + ⋯ + aNsN = 1(1 + s/|p₁|)(1 + s/|p₂|)⋯(1 + s/|pN|)　≈　11 + sτE

上一頁的 RC 電路只有一個極點。晶片上的長導線則是一長串 RC，切成 N 段就有 N 個極點。同樣的三張臉仍然適用：

① 時域：步階響應N 個指數 epit 疊加，決定 50% 延遲 t50。
② s 平面：N 個極點全在負實軸；最靠近原點的主極點最慢、最重要。
③ 頻域：頻寬−3 dB 頻寬決定訊號能跑多快；極點越多，高頻掉得越快。

第 1 節先把兩個標準元件與導線換成 RC 電路，再一步步推導 H(s)（先用 2 段當例子，再推廣到 N 段）；第 2 節用滑桿調整導線、看 H(s) 多項式；第 3 節畫出極點地圖，比較完整模型與一階近似；第 4 節說明這些延遲如何決定晶片的最高時脈。

Bonjour！我是 Laplace。點我聽故事！

1從實際電路到 RC 模型，再推導 H(s)

先看實際電路：兩個標準元件用導線連接

以兩個反向器為例：驅動元件 A 的輸出經過一條長度 L 的金屬導線，接到接收元件 B 的輸入。

實際電路：每個標準元件內部是 PMOS（上拉）與 NMOS（下拉）；導線是一條細長的金屬。

A 的輸出由 0 翻成 1 時，PMOS 導通、NMOS 關閉。導通的 PMOS 相當於一個電阻 Rd，負責把後面所有電容充到 VDD。三個部分各自換成 R、C：

RC 等效電路：元件 A 換成步階電源、導通電阻 Rd 與輸出端寄生電容 Cself；導線換成 π 模型；元件 B 從外面只看得到閘極，只剩一顆電容 Cin。

套用 Elmore 規則（每顆電容 × 電源到它的電阻總和），從電源一路算到 Vout：

τE = Rd·(Cself + Cw + Cin) + Rw·(Cw2 + Cin)
  • 第一項：Rd 要替後面所有電容充電；第二項：Rw 只替它後面的電容充電。
  • 短導線：Rw 小到可以忽略，整個電路退化成〈（一）RC 電路〉的一階 RC：τ = Rd(Cself + Cw + Cin)。
  • 輸出由 1 翻成 0 時改由 NMOS 放電，Rd 換成 NMOS 的導通電阻（通常比 PMOS 小），所以上升、下降延遲不同。

逐步推導

為了讓式子簡潔，下面先把 Cself 忽略（它通常比導線電容小），並把導線切成 2 段。

先用最小的非平凡例子：導線切成 2 段。推導 2 段的 H(s) 後，再用 ABCD 矩陣推廣到 N 段。

2CMOS 輸出驅動長導線：H(s) 變成 N 階

反向器導通時，可看成電阻 Rd 接到電源。長導線每單位長度都有電阻與電容（此處用 r = 0.2 Ω/µm、c = 0.2 fF/µm），把它切成 N 段 RC，最後接到下一級的閘極電容 CL。

H(s) 寫成多項式

依第 1 節第 5 步：每段的 ABCD 矩陣 [1+sRkCk, Rk; sCk, 1] 連乘，輸出端開路，得 H(s) = 1 / A(s)。分子是常數 1，所以沒有零點。

H(s) 告訴我們的事

3極點地圖與主極點近似：N 階系統為什麼像一階？

第 2 節的參數會沿用到這裡。導線只有 R 和 C、沒有電感，所以 N 個極點全落在負實軸上，不會振盪。離原點最近的那個（主極點）衰減最慢，主導了整個響應。

橫軸為 |σ|（1/ns，對數刻度），越往右衰減越快。橘色為主極點 p₁，藍色為其餘極點，紫色豎線為 1/τE。

實線：完整 N 階　虛線：1/(1+sτE)　點線：只留主極點 1/(1+s/|p₁|)

|H(j2πf)|（dB）。高頻時完整模型掉得更快：每多一個極點，斜率多 −20 dB/dec。

4晶片能跑多快？最高時脈的原理

原理：訊號必須在下一個時脈邊緣之前「到站」

同步電路中，資料在時脈邊緣從正反器（flip-flop）送出，經過邏輯閘與導線，必須在下一個時脈邊緣之前抵達下一個正反器，而且還要提早一段建立時間 tsetup 穩定下來。所以時脈週期至少要等於最慢那條路徑（關鍵路徑）的總延遲：

Tclk ≥ tcq + tlogic + twire + tsetup　⟹　fmax = 1Tclk,min

其中導線延遲 twire 就來自 H(s)：接收端反向器在電壓過 50% 時切換，所以 twire = 步階響應到 50% 的時間 t50（第 2 節）。導線越長，主極點越靠近原點，t50 越長，fmax 就越低。

導線長度、Rd、CL、N 沿用第 2 節滑桿。閘延遲與正反器時間為教學示意數值。

時序預算：一個時脈週期內要放得下的延遲。紫：tcq + tsetup　藍：tlogic　橘：twire

把時脈方波送進導線：H(s) 是低通濾波器

方波可看成一連串上升、下降的步階，輸出就是步階響應的疊加（線性系統）。頻率一高，每半個週期的時間不夠電容充放電，輸出擺幅變小；擺幅太小時，輸出只在 50% 附近小幅抖動，接收端分不出 0 和 1，時脈等於消失了。圖中畫的是開機一段時間後的穩態。

藍：反向器送出的方波（輸入）　橘：導線末端的電壓（輸出）　虛線為 50% 切換門檻。

實際晶片怎麼辦？長導線會插入中繼器（repeater），讓延遲從隨 L² 成長變成隨 L 成長；關鍵路徑太長則用管線化（pipelining）切成多級。另外，時脈越高功耗越大（P ∝ C V2 f），散熱也會限制最高時脈。

🔧給未來的 IC 設計師

Laplace 轉換和轉移函數不只是考試題目，而是你將來進入 IC 設計領域時天天會遇到的語言。

製程越先進，電晶體越快，導線卻因為變細而電阻變大，長導線延遲常常比邏輯閘還大。這一頁的觀念，正是工程師每天面對的問題：

  • 靜態時序分析（STA）：工具從佈局抽出每條線的 RC 網路，用 Elmore 延遲（就是 a₁）與更高階的矩（a₂、a₃…）計算延遲。
  • 時序收斂：看到違例時，要判斷是邏輯太深還是導線太長，再決定插中繼器、加粗導線、換到上層金屬或調整擺放位置。
  • 時脈樹合成：把時脈以極小偏移送到上百萬個正反器，本質上是在管理大量 RC 樹的延遲。

工具會自動計算這些數字，但要看懂報告、做出正確的修正決策，你必須知道延遲從哪裡來，也就是 H(s) 的極點告訴你的事。

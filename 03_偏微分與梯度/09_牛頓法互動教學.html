0一句話直覺：沿著切線滑到 x 軸

新的猜測 ＝ 舊的猜測 − 函數值 ÷ 斜率
xn+1 = xn − f(xn)f′(xn)
① 先猜一個 x₁目標是找 c 使 f(c) = 0（方程式的根，也就是零點）。先畫圖，猜一個靠近根的 x₁。
② 畫切線、找交點在曲線上的點 (xn, f(xn)) 畫切線，切線和 x 軸的交點就是新的猜測 xn+1。
③ 夠準就停當 |xn − xn+1| 小於要求的精度，就用 xn+1 當答案；否則回到 ②。每做一次叫一次迭代（iteration）。

為什麼要學？很多方程式沒有公式解，例如 cos x = x；計算機算 √2 也是用類似方法。AI 裡的「二階最佳化」方法，也是從牛頓法發展出來的（第 4 節）。

靠近根之後，牛頓法的正確位數大約每次翻倍（例如 1 → 3 → 7 → 14），這叫二次收斂（quadratic convergence）；二分法每次只多大約 0.3 位。

4牛頓法和梯度下降是親戚

把「找根」改寫成「找最小值」：f(x) = 0 的根，就是 g(x) = ½f(x)² 的最小值（g ≥ 0，只有在根的地方等於 0）。

📌 牛頓法 ＝ 自動選步長的梯度下降。梯度下降的 η 要人工去調；牛頓法每一步用 η = 1/f′(xn)² 自動決定該走多遠，所以快很多。代價是要能算出 f′(x)，而且它不能是 0。

延伸：如果要找 g(x) 的最小值，就用牛頓法解 g′(x) = 0，得到 xn+1 = xn − g′(xn) / g″(xn)，也就是步長 η = 1/g″ 的梯度下降。這是 AI 裡「二階最佳化」（如 L-BFGS）的出發點。
